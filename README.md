# ابر | ABR Keyboard

صفحه‌کلید اندرویدی فارسی با رابط کاربری الهام‌گرفته از ابر.

## ساخت و نصب
پس از اجرای موفق GitHub Actions، فایل APK را از بخش Actions و Artifact با نام `abr-keyboard-debug` دریافت کنید.

## فعال‌سازی
1. برنامه «ابر» را نصب و باز کنید.
2. گزینه «فعال‌سازی صفحه‌کلید» را بزنید.
3. «صفحه‌کلید ابر» را فعال کنید.
4. از گزینه انتخاب صفحه‌کلید، ابر را انتخاب کنید.

## وضعیت نسخه
این نسخه اولیه دارای ورود کلیدهای فارسی و انگلیسی، فاصله، حذف و کلید اقدام است. تشخیص واقعی دست‌خط از روی رسم حروف هنوز پیاده‌سازی نشده است.
