# ابر | ABR Keyboard

صفحه‌کلید دست‌نویس اندروید با سطح نوشتن ابری؛ این پروژه عمداً صفحه‌کلید QWERTY یا ردیف کلیدهای حروف ندارد.

## قابلیت‌های پیاده‌سازی‌شده در شاخه فعلی
- فضای نوشتن لمسی با طراحی ابر نیمه‌شفاف
- استفاده از ML Kit Digital Ink برای تشخیص دست‌خط؛ ابتدا برچسب زبان فارسی و در صورت نبود شناسهٔ مدل، مدل عربی به‌عنوان مسیر جایگزین
- نمایش حداکثر سه پیشنهاد تشخیص و درج متن با انتخاب کاربر
- دو ضربهٔ سریع برای درج فاصله
- لمس هم‌زمان دو انگشت برای اجرای Enter یا newline
- نگه‌داشتن و کشیدن انگشت به راست برای حذف تکرارشونده با فاصلهٔ تقریبی ۲۰۰ میلی‌ثانیه
- لمس نوار آبی تیره برای بستن صفحه‌کلید و بازگشت به پیمایش

## ساخت APK
هر بار که تغییری به شاخهٔ `main` ارسال شود، GitHub Actions تلاش می‌کند نسخهٔ Debug را بسازد. در صورت موفقیت، از بخش Actions فایل Artifact با نام `abr-keyboard-debug` قابل دریافت است.

## فعال‌سازی در اندروید
1. برنامه «ابر» را نصب و باز کنید.
2. «فعال‌سازی صفحه‌کلید» را بزنید و ABR Keyboard را در تنظیمات فعال کنید.
3. به برنامه برگردید و «انتخاب صفحه‌کلید ابر» را بزنید.

## محدودیت‌ها و وضعیت آزمون
- دانلود اولیهٔ مدل تشخیص به اینترنت نیاز دارد.
- پشتیبانی واقعی از فارسی وابسته به در دسترس بودن مدل فارسی در نسخهٔ ML Kit دستگاه/مخزن است. مدل عربی جایگزین، تضمین تشخیص درست همهٔ حروف و واژه‌های فارسی نیست؛ باید با نمونه‌های واقعی فارسی آزموده شود.
- این commit هنوز به‌معنای APK تأییدشده نیست. تنها پس از سبز شدن GitHub Actions و نصب و آزمون روی گوشی Xiaomi با Android 11 می‌توان نسخه را قابل‌تحویل دانست.
